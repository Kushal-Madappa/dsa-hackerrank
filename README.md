# dsa-hackerrank

My HackerRank solution log. All solutions are in **Python 3**, written to pass
HackerRank's grader directly — no extra scaffolding.

## Structure

```
dsa-hackerrank/
├── warmup           # 1★ warm-up problems (Solve Me First, Compare the Triplets, etc.)
├── implementation   # Algorithmic implementation (Grading Students, etc.)
├── strings          # String manipulation (Camel Case, Pangrams, etc.)
├── python           # Python domain (Introduction, Data Types, Itertools, etc.)
└── sql              # SQL practice (Basic Select, Joins, etc.)
```

Each file has a 2-line header: `# HackerRank: <name>` and `# <url>`.
